# Языковой портал

Учебный проект для практического задания КИМ 09.02.09-1-2027.

## Технологии

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3

## Запуск на начальном этапе

Откройте папку проекта в Visual Studio Code и запустите `index.html` через расширение Live Server.

Bootstrap подключён локально из папки `bootstrap`, поэтому для отображения стилей и компонентов не требуется CDN.

## Структура

- `index.html` - главная страница
- `courses.html` - страница курсов
- `signup.html` - страница записи
- `css/style.css` - собственные стили проекта
- `js/` - JavaScript-файлы проекта
- `bootstrap/` - локальные файлы Bootstrap 5.3.3
- `images/` - изображения
- `database/` - файлы базы данных и SQL
- `server/` - серверная часть
- `docs/` - диаграммы и прототипы
