# Языковой портал

Учебный проект для практического задания КИМ 09.02.09-1-2027.

Сайт разработан для школы иностранных языков «Языковой портал». На сайте можно посмотреть доступные курсы, рассчитать примерную стоимость обучения и записаться на бесплатный урок.

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- Node.js
- SQLite
- Figma

## Страницы сайта

**Главная страница (`index.html`)**
- Информация о школе
- Преимущества обучения
- Отзывы учеников
- Контактная информация

**Страница курсов (`courses.html`)**
- Английский язык
- Китайский язык
- Итальянский язык
- Испанский язык
- Поиск курсов
- Калькулятор стоимости обучения

**Страница записи (`signup.html`)**
- Форма записи на бесплатный урок
- Проверка ФИО, телефона и электронной почты
- Выбор курса
- Согласие на обработку персональных данных
- Отправка заявки на сервер

## База данных

Для хранения заявок используется SQLite.

После отправки формы сервер проверяет данные и сохраняет заявку в базу данных.

Файл базы данных `applications.sqlite` создаётся автоматически при запуске приложения. Он исключён из Git, чтобы не загружать персональные данные в репозиторий.

## Как запустить проект

Для запуска необходим Node.js версии 22.13 или новее.

1. Открыть папку проекта в Visual Studio Code.
2. Открыть терминал.
3. Выполнить команду:

```powershell
npm.cmd start
```

4. Открыть сайт в браузере:

http://localhost:3000

Для проверки сохранённых заявок откройте второй терминал и выполните:

```powershell
npm.cmd run db:check
```

Для остановки сервера нажмите `Ctrl + C` в терминале, в котором он запущен.
