ПОДКЛЮЧЕНИЕ БАЗЫ ДАННЫХ К ФОРМЕ ЗАПИСИ

1. Что находится в архиве
- package.json - команды запуска проекта;
- server/server.js - сервер сайта и обработчик заявок;
- server/db.js - подключение к SQLite и добавление заявок;
- server/check-db.js - проверка количества сохранённых заявок;
- database/schema.sql - структура таблицы заявок;
- js/form.js - проверка формы и отправка данных на сервер;
- signup.html - обновлённая страница записи.

2. Как установить файлы
Распакуй архив. Скопируй содержимое папки yazykovoy-portal-backend-update в корень своего проекта:
C:\Users\user\Desktop\yazykovoy-portal

Соглашайся на объединение папок и замену файлов.
Файл signup.html замени новым.
Файл js/form.js замени новым.
Добавь папки server и database/schema.sql.
package.json положи в корень проекта.
Bootstrap, css/style.css, css/signup.css, index.html и courses.html не заменяй.

3. Проверка Node.js
Открой терминал VS Code в корне проекта и выполни:
node --version

Нужна версия Node.js 22.13.0 или новее. В этой работе SQLite используется через встроенный модуль node:sqlite, поэтому устанавливать отдельную библиотеку SQLite не нужно.

4. Запуск
Если Live Server запущен, его можно остановить: перейди в терминал, где он работает, и нажми Ctrl + C.
Открой терминал VS Code в корне проекта и выполни:
npm start

В браузере открой:
http://localhost:3000

Для страницы записи:
http://localhost:3000/signup.html

Важно: после подключения базы данных для проверки формы используй адрес localhost:3000, а не адрес Live Server 127.0.0.1:5500.

5. Проверка сохранения
Заполни форму правильными тестовыми данными и отправь заявку.
На странице должно появиться сообщение об успешном сохранении и номер заявки.
Затем открой второй терминал VS Code (сервер не останавливай) и выполни:
npm run db:check

Команда покажет количество записей и курс последней заявки. Файл базы данных автоматически появится здесь:
database/applications.sqlite

6. Остановка сервера
В терминале, где работает сервер, нажми Ctrl + C.

7. Git
Файл database/applications.sqlite не нужно отправлять в GitHub, так как в .gitignore уже предусмотрено исключение файлов SQLite. Исходная структура базы database/schema.sql должна быть в репозитории.

Примечание
Данные в этой учебной работе проверяются и на стороне браузера, и повторно на сервере. В базу попадают только заявки с корректными полями и согласием. В реальной эксплуатации понадобятся дополнительные меры защиты и политика обработки персональных данных.
