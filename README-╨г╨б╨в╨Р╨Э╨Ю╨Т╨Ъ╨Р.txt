Страница записи на бесплатный урок

Скопируйте файлы из архива в корневую папку проекта yazykovoy-portal.
Папки css и js нужно объединить с существующими папками проекта.
Файл signup.html замените новым.
Файл js/form.js добавьте в папку js.
Файл css/signup.css добавьте в папку css.

Остальные страницы, общий файл css/style.css и Bootstrap заменять не нужно.

Что работает на этом этапе:
- обязательные поля формы;
- проверка ФИО на кириллицу и пробелы (фамилия и имя, при желании отчество);
- форматирование и проверка телефона +7(XXX)-XXX-XX-XX;
- встроенная проверка формата электронной почты;
- обязательный выбор курса;
- обязательное согласие на обработку персональных данных;
- показ ошибок рядом с полями;
- подстановка курса из ссылки вида signup.html?course=english.

Важно: сейчас реализована проверка на стороне браузера. Запись в базу данных ещё не подключена.
Это будет отдельный следующий этап, чтобы не создавать видимость сохранения данных там, где его пока нет.
