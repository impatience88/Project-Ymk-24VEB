Файлы для этапа "Страница курсов".

1. Распакуйте архив в корень своего проекта yazykovoy-portal.
2. Согласитесь на замену courses.html.
3. Папки css, js и images объедините с существующими папками проекта.
   Не удаляйте style.css, main.js и другие файлы.
4. В courses.html подключаются:
   - bootstrap/css/bootstrap.min.css
   - css/style.css
   - css/courses.css
   - bootstrap/js/bootstrap.bundle.min.js
   - js/main.js
   - js/calculator.js
5. Откройте courses.html через Live Server.

Изображения скопированы из приложения №1 преподавателя.
Цены взяты из файла "данные для расчета стоимости курса.txt".
В исходных материалах нет коэффициентов для изменения стоимости в зависимости
от длительности занятия. Поэтому выбор длительности есть, но цену он не меняет.
Калькулятор считает стоимость за месяц: цена одного занятия * количество занятий.
